## Changes verified

- Top-two choices are compared; first choice wins if within 3% of the best value.
- Search complete alternative sets/primaries rather than leaving missing slots.
- Protect later characters' eligible slot supply with a matching check.
- Keep a valid available equipped build if it is over 5% stronger.
- Enforce required stat minima/maxima, including relative targets. Reject solver
  fallbacks that silently drop them. Report unsatisfied constraints explicitly.
- Normalize character secondary preferences against population popularity and
  primary-eligible slots. Keep flat/percent groups and the 0.8–1.2 multiplier.
- Report alternatives to first-choice sets and primaries in result messages.

Speed was previously the largest generated preference for all 340 characters.
It is now largest for six; all eight stat groups lead for some characters.
Wampa now has Tenacity 1.00, Health 0.66 and Speed 0.53. Chewbacca has Tenacity
0.99 and Speed 0.57. These are relative preferences, not absolute combat values.

## Remaining tradeoffs

R2-D2 improves from the old GG mode's 261 Speed / 23.60 GG to 306 Speed / 38.78 GG.
Normal stat weights give him 302 Speed / 34.24 GG, but more Potency (107.94% versus
82.13%). Morgan's plain GG result improves from 256 Speed / 19.90 GG to 290 Speed /
36.57 GG; normal mode gives 309 Speed / 35.66 GG, but less Health (75,033 versus 90,217).

Chewbacca now gets six mods instead of three. However, the top-two options include
a damage-focused build. Revised plain GG gives 54.46% Tenacity and character-weighted
GG 50.64%, versus 81.29% for normal stat weights. Wampa also loses Tenacity relative
to normal mode (80.31% character-weighted versus 97.42%). These are warnings against
equating GG with role effectiveness, even with the corrected secondary preferences.
This snapshot has no configured stat-target requirements, so no new role floors were
silently added. A required Tenacity or Speed floor can now constrain either GG mode.

Recommendation: plain GG is the strongest measured option for this roster's GG
objective. Keep character-weighted GG as an alternative; it has not demonstrated a
clear advantage. Use explicit role-critical stat floors or normal stat-weight plans
for characters where those tradeoffs are unacceptable. Do not increase the character
multiplier merely to make this one snapshot win its own scoring metric.
